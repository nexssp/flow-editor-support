# Nexss Flow for Claude Code

This plugin starts Flow core's native LSP for `.nflow` files. Diagnostics and code intelligence come from `nflow lsp`; the bundled `lsp/nflow-lsp.js` only checks the selected core version and forwards stdio to the executable. Install the latest stable Flow release (this editor-support revision is tested against v0.67.0) and make it available on Claude Code's `PATH`, or set `NFLOW_BIN` in the environment Claude Code inherits. The launcher still accepts v0.44.2 and newer, but older cores may not expose current language features.

Keep `/flowfmt` as the explicit formatting command. It forwards to the core `nflow fmt` command and honors `NFLOW_BIN`; it contains no formatting rules and does not provide automatic format-on-save. Claude Code does not color source files, so syntax highlighting remains the responsibility of the host editor. LSP capabilities—including diagnostics, completion, hover, and formatting—are provided by the installed core and can grow with newer releases; see the [current Flow LSP implementation](https://github.com/nexssp/flow/blob/main/cli/lsp.go).
